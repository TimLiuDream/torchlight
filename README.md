# torchlight

《火炬之光》文字版 —— 单文件 Python 暗黑系刷宝 Roguelite。

## 运行

```bash
python torchlight_text.py              # 开始游戏
python torchlight_text.py --autotest   # 自检(机器随机操作, 存档写入临时目录)
```

要求 Python 3.8+，无第三方依赖。Windows 终端直接跑即可（已处理 ANSI 颜色）。

## 玩法

- **三个职业**：灰烬法师（高伤技能）/ 狂战士（必暴旋风斩）/ 工程师（治疗+输出）
- **随机遭遇**：每层掷骰决定——怪物群 / 宝箱（陷阱箱、拟态怪）/ 精英怪 / 回春泉 / 流浪商人 / 空房间
- **词缀装备**：白/蓝/金/橙四档稀有度，层数越深高档概率越高，首领必掉稀有以上
- **篝火营地**（每 3 层）：休息回血 / 商店买药 / 卖装备 / 传送跳层
- **楼层系统**：每层显示建议等级，可 `[r]` 反复重刷，营地 `[7]` 可跳层
- **自动存档**：`save.json`，每清一层自动写入；死亡删档，roguelite 规矩

## 结构

全部逻辑在 `torchlight_text.py`（约 600 行）：装备/怪物/事件均为数据驱动，
调数值直接改顶部的常量表（`CLASSES`、`RARITY_MULT`、各事件概率）。
